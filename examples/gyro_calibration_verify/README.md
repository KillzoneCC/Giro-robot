# Калибровка и проверка гиро-робота

Калибровка по **всем плоскостям**. **Терминал подсказывает, когда переворачивать** робота. После калибровки данные сохраняются в EEPROM — **после перезагрузки робот сразу встаёт** в нормальное положение.

## Для макетной платы

Arduino Nano + MPU6050 + шаговые моторы (пины D3,D5,D9,D10).

## Как работает

### Первый запуск (калибровка)

1. Откройте Serial Monitor (115200) **до** включения.
2. Терминал выводит подсказки: **«ПЕРЕВЕРНИТЕ: положите на спину»**, обратный отсчёт 5…4…3…2…1, затем сбор данных.
3. **6 позиций**: вертикально → на спине → левый бок → правый бок → нос вверх → нос вниз.
4. **Запоминание нуля**: держите вертикально 2 сек.
5. Калибровка сохраняется в EEPROM.

### После перезагрузки

Робот загружает калибровку из EEPROM и **сразу встаёт** в нормальное положение.

## Serial Monitor / Plotter

- **115200** бод
- Вывод: `угол, цель, выход_PID` — для Serial Plotter (Ctrl+Shift+L)
- Команды:
  - **c** — перекалибровать (6 плоскостей + запоминание + сохранение)
  - **z** — новый ноль (запомнить текущее положение и сохранить)
  - **e** — стереть калибровку из EEPROM (после перезагрузки — полная калибровка)

## Настройка оси баланса

В коде `USE_PITCH_FOR_BALANCE`:
- **0** — баланс по roll (наклон влево-вправо)
- **1** — баланс по pitch (вперёд-назад)

Подберите под вашу механику.

## PID

По умолчанию: Kp=7, Ki=0, Kd=0.12. Если робот не ловит баланс — подстройте в коде (PID_KP, PID_KD).
