# IMU Calibration — в стиле DJI Tello

Экспериментальная 6-точечная калибровка MPU6050 для гиро-робота. Аналогично калибровке IMU в DJI Tello: робот укладывается на 6 плоскостей, скетч собирает данные и вычисляет offsets для акселерометра и гироскопа.

## Зачем это нужно

- **DJI Tello** калибрует IMU по всем осям (roll, pitch, yaw), чтобы дрон летал стабильно без дрейфа.
- **Гиро-робот** с MPU6050 после такой калибровки получает точные углы и может сразу вставать и держаться на целевых координатах.

Без калибровки гироскоп даёт смещение при покое, акселерометр — неверный угол. Результат: дрейф, «уход» нуля, нестабильный баланс.

## Подготовка

1. **Батарея** заряжена минимум на 50%.
2. **Ровная поверхность** (стол, пол без наклона). Проверьте уровнем.
3. **Без магнитных полей** и металла рядом (компьютер, микроволновка).
4. **Подключение MPU6050**: VCC→3.3V, GND→GND, SDA→A4, SCL→A5.

## Запуск

1. Откройте скетч в Arduino IDE.
2. Выберите плату Arduino Nano.
3. Serial Monitor: **115200** бод.
4. Отправьте **`s`** для старта калибровки.

## 6 позиций (как у Tello)

| № | Позиция | Описание |
|---|---------|----------|
| 1 | Стоит вертикально | Колёса вниз, робот в рабочем положении |
| 2 | На спине | Колёса вверх |
| 3 | На левом боку | X вверх |
| 4 | На правом боку | X вниз |
| 5 | Нос в потолок | Y вверх |
| 6 | Нос в пол | Y вниз |

Для каждой позиции: уложите робота, дождитесь окончания сбора (~2.5 сек), переходите к следующей.

## Результат

После 6-й позиции скетч выведет в Serial:

- `ACCEL_OFFSET_X/Y/Z` — смещения акселерометра
- `GYRO_BIAS_X/Y/Z_DPS` — смещения гироскопа (deg/s)
- `ACCEL_SCALE_X/Y/Z` — масштабные коэффициенты

**Скопируйте эти значения** в основной код (`fgggggggggggg5.ino`) и примените при чтении IMU:

```cpp
ax_cal = (ax - ACCEL_OFFSET_X) * ACCEL_SCALE_X;
ay_cal = (ay - ACCEL_OFFSET_Y) * ACCEL_SCALE_Y;
az_cal = (az - ACCEL_OFFSET_Z) * ACCEL_SCALE_Z;
gx_cal = gx - GYRO_BIAS_X_DPS;  // и т.д.
```

## Команды

- **`s`** или **`S`** — начать калибровку
- **`r`** или **`R`** — повторить калибровку

## Рекомендации

- Калибруйте при той же температуре, при которой будете использовать робота.
- Повторяйте калибровку после падения, транспортировки или смены среды.
