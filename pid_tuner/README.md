# PID Tuner — настройка PID для Giro-Robot

Приложение для управления PID-регулятором балансирующего робота Giro-Robot через USB (Serial).

## Установка

1. Установите Python 3.7 или новее (если ещё не установлен).
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python pid_tuner.py
```

## Использование

1. **Подключите Arduino** к компьютеру по USB.
2. **Выберите COM-порт** в выпадающем списке (нажмите «Обновить», если порт не появился).
3. Нажмите **«Подключить»**.
4. Введите значения **Kp**, **Ki**, **Kd** и **Limit**.
5. При включённой **«Авто-отправка при изменении»** значения отправляются в Arduino сразу при изменении полей.
6. Либо нажмите **«Отправить в Arduino»** вручную.
7. **«Прочитать с Arduino»** — запрашивает текущие PID-параметры с робота.
8. **«Сохранить в EEPROM»** — сохраняет текущие PID в память Arduino (они будут загружаться при следующем включении).
9. **«График PID»** — открывает окно с графиками target, angle, P, I, D, output.
10. **«Скорость моторов»** — открывает окно с текущей скоростью в м/с и шаг/с (требует включённый график).

## Скорость моторов

Для отображения скорости в м/с настройте `speed_motor.h` в прошивке Arduino:
- `STEPS_PER_REV` — шагов на оборот (200, 400, 800…)
- `WHEEL_DIAMETER_M` — диаметр колеса в метрах (0.05 = 5 см)

## Протокол

- Скорость: 115200 бод
- Команда установки PID: `f,kp,ki,kd,limit`
- Команда чтения: `P`
- Команда сохранения в EEPROM: `w`

## Требования

- Arduino с прошивкой Giro-Robot
- Закрыть Serial Monitor в Arduino IDE при использовании приложения (один порт — одно приложение)
