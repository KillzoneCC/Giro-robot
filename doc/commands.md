# Serial-команды

Скорость порта: **115200 бод**. Завершение команды — перевод строки.

Часть ответов в прошивке выводится в **коротком виде** (экономия Flash на Nano): например готовность `OK`, после загрузки калибровки из EEPROM — `+`, частота `100Hz`, переключатели `D`/`M` отвечают строками вида `D1`/`D0`, `M1`/`M0`; подтверждение режима автотюна — строка вида `a0` / `a1` / `a2`. Команда **`G`** зарезервирована и всегда отвечает `G0` (режим Serial Plotter отключён из‑за лимита Flash). Поля **`TLM,...`** и **`STATUS …`** для автотюна и pid_tuner не изменены.

## Управление движением

| Команда | Действие |
|---|---|
| `V,speed_mps,turn` | Скорость в м/с + поворот (-1..1). Пример: `V,0.5,0`. |
| `V,0,0` | Остановка с балансом на месте (плавное торможение через Speed PID). |
| `v,linear,turn` | linear ∈ [-1..1] — для совместимости. `v,0.5,0` ≈ 0.5·`MAX_TARGET_SPEED_MPS`. |
| `s` / `S` | Полный стоп: цель 0, моторы выключены. |

При активном режиме автотюна (`a,1` или `a,2`) команды `v` / `V` **принимаются и парсятся**, но цель скорости не меняется (принудительный баланс на месте).

## Калибровка и нуль

| Команда | Действие |
|---|---|
| `c` / `C` | Полная калибровка IMU (6 позиций). |
| `z` | Запомнить нуль: удерживайте робота ровно 2 сек. |
| `z,<angle>` | Установить нуль вручную (градусы). |
| `e` / `E` | Очистить EEPROM (калибровка + PID). |

Подробнее: [calibration.md](calibration.md).

## PID

Два независимых PID: **Angle PID** (внутренний, по умолчанию) и **Speed PID** (внешний,
доступен через суффикс `2`).

| Команда | Angle PID | Speed PID |
|---|---|---|
| Показать коэффициенты | `P` | `P2` |
| Установить все | `f,kp,ki,kd,lim` | `f2,kp,ki,kd,lim` |
| Сохранить в EEPROM | `w` | `w2` |

Точечная настройка Angle PID:

| Команда | Действие |
|---|---|
| `p,<kp>` | Kp |
| `i,<ki>` | Ki |
| `d,<kd>` | Kd |
| `l,<lim>` | Предел выхода PID (шаг/с, ≥ 100) |

## Отладка

| Команда | Действие |
|---|---|
| `D` | Вкл/выкл текстовую отладку; ответ `D1` или `D0` |
| `G` | Зарезервировано; ответ всегда `G0` (Serial Plotter отключён на Nano из‑за Flash) |
| `M` | Вкл/выкл монитор скорости; ответ `M1` или `M0` |
| `?` | Статус: `STATUS fall=0/1 hz=NN atz=M` — падение, частота цикла, режим автотюна (0/1/2) |

## Автотюн и телеметрия (host-driven)

Режимы и поток **только в RAM** (сохранение PID по-прежнему `w` / `w2`).

| Команда | Действие |
|---|---|
| `a,<mode>` | Автотюн: `0` — выкл; `1` — баланс на месте, каскад Speed→Angle (цель скорости 0); `2` — только Angle PID (`angleOffset` с внешнего контура принудительно 0). |
| `x,<0\|1>` | Машиночитаемая телеметрия CSV: `1` — вкл (строчки `TLM,...` каждый проход цикла), `0` — выкл. При вкл. отключается режим `D`. При включении дополнительно выводится короткая строка-маркер `TH` (аналог заголовка; полный состав полей см. ниже). |
| `r` | Полный сброс контуров: то же, что внутри `resetAllControlState()` (без изменения логики `FallHandler`). Ответ краткий: `rOK`. Используется ПК после паузы при падении для согласованного возобновления. |

При падении (`fall` активен) до выполнения основного цикла выводится маркер **`TLM_FALL`** (если включён `x,1`), затем цикл прерывается до восстановления.

Формат строки **`TLM,...`** (поля через запятую после префикса):

`f,p,g,ta,m,spdE,spP,spI,spD,angE,aP,aI,aD,aOff,v,vw,atz,settle,tgt,stab`

- `f` — всегда `0` в рабочем режиме (резерв под fall в том же формате не используется; fall см. `TLM_FALL`).
- `p` — pitch (°), `g` — скорость по pitch гироскопа (°/с), `ta` — целевой угол, `m` — команда моторов (шаг/с), далее вклад Speed PID и Angle PID, `aOff` — фактический угол наклона с внешнего контура, `v` / `vw` — фузия и колёса (м/с), `atz` — режим автотюна, `settle` — окно успокоения после recovery (1 = Speed PID не обновляется), `tgt` — целевая скорость twist (м/с), `stab` — стабилизация включена (1/0).

## Частота цикла

| Команда | Действие |
|---|---|
| `H` | Показать текущую частоту в виде `NNHz` (число и суффикс без пробела) |
| `H,<hz>` | Установить 25–200 Гц, сохранить в EEPROM; подтверждение также `NNHz` |

## Примеры

```
c                          # калибровка
V,0.3,0                    # 0.3 м/с вперёд
f,280,0.005,0.0045,7500    # задать Angle PID
w                          # сохранить Angle PID
f2,3.5,0.05,0.02,10        # задать Speed PID
w2                         # сохранить Speed PID
x,1                        # машиночитаемая телеметрия CSV (TLM,...)
a,2                        # автотюн: только Angle PID; затем sweep из pid_tuner
a,0
x,0
