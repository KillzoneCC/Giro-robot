# Настройка PID

## Порядок

1. Сначала подстраивают **Angle PID** (внутренний контур), задавая `V,0,0`
   (баланс на месте, `targetSpeed = 0` → Speed PID выдаёт ~0°).
2. Затем — **Speed PID** (внешний контур), с небольшими целевыми скоростями
   (`V,0.2,0`, `V,-0.2,0`), наблюдая качество разгона/торможения.

## Методика для Angle PID

- Начните с нулевых Ki и Kd: `f,<Kp>,0,0,7500`. Увеличивайте Kp, пока робот не начнёт
  устойчиво стоять с небольшими медленными колебаниями.
- Добавьте Kd (0.003–0.01) — колебания должны демпфироваться.
- Небольшое Ki (0.002–0.01) уберёт статическую ошибку при слегка смещённом нуле.
- `limit` — предел выхода в шагах/с. Верхний потолок — `MOTOR_SPEED_LIMIT` из
  [config.h](../code/Giro_robot/Giro_robot/config.h). Слишком низкий предел режет
  реакцию при больших возмущениях, слишком высокий — позволяет дёргать моторы.

Сохранить: `w`.

## Методика для Speed PID

- Speed PID преобразует ошибку скорости в угол наклона. Единицы: °/(м/с).
- Типичный диапазон: Kp 2–5, Ki 0.02–0.1, Kd 0.01–0.05, angleLimit 8–15° (чтобы
  Angle PID мог отработать без срыва в падение).
- Команды: `f2,kp,ki,kd,anglelim`, сохранить `w2`.
- `ANGLE_OFFSET_SMOOTH` в `config.h` сглаживает выход Speed PID перед передачей в
  Angle PID: 0.2 — плавно, 0.5 — отзывчиво, 1.0 — без сглаживания.

## Serial Plotter

Arduino IDE → Tools → Serial Plotter → команда `G`.

Каналы вывода (8): `targetAngle, angle, error, P, I, D, motorOutput, vFused`.

Повторно `G` — выключить.

## Исторические пресеты (Angle PID)

Реально опробованные наборы (подбираются под конкретное механическое исполнение):

```
f,280,0.005,0.0045,7500
f,290,0.005,0.006,7500
f,300,0.005,0.007,8000
f,340,0.004,0.01,7700
f,350,0.005,0.01,7500
f,355,0.005,0.01,7500
f,380,0.005,0.01,8000
f,400,0.005,0.012,8000
```

Эти значения — отправная точка, а не гарантия. Проверяйте на вашем роботе.
