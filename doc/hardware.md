# Железо

## Компоненты

| Компонент | Модель/параметры |
|---|---|
| Контроллер | Arduino Nano (ATmega328P, 16 МГц) |
| IMU | MPU6050 (I2C, 400 кГц) |
| Драйверы шаговиков | TMC2208 (×2), 16 микрошагов |
| Шаговые моторы | 200 шаг/оборот, 1.8° |
| Колёса | Диаметр 72–78 мм |
| Размеры корпуса | Ш 134 мм × В 146 мм, масса ~1.1 кг |

## Пины (config.h)

| Назначение | Пин Nano |
|---|---|
| Motor 1 STEP | D3 |
| Motor 1 DIR | D5 |
| Motor 2 STEP | D9 |
| Motor 2 DIR | D10 |
| Stepper ENABLE (оба драйвера) | D8 (активный LOW) |
| I2C SDA | A4 |
| I2C SCL | A5 |

Таймеры: Timer1 → мотор 1, Timer2 → мотор 2.
Базовые частоты — `TIMER1_BASE_HZ = 2 000 000`, `TIMER2_BASE_HZ = 15 625`.
Максимальная скорость моторов — `MOTOR_SPEED_LIMIT = 15625` шаг/с.

## Питание

- Двигатели: отдельный источник, соответствующий току TMC2208 (обычно 9–24 В).
- Arduino: от USB или VIN, логика 5 В.
- Общая земля обязательна.

## Физические параметры в прошивке

В [speed_motor.h](../code/Giro_robot/Giro_robot/speed_motor.h):

```
STEPS_PER_REV     3200      // 200 × 16 микрошагов
WHEEL_DIAMETER_M  0.078     // 78 мм
```

Пересчёт `шаг/с ↔ м/с` использует эти константы. Если у вас другой диаметр
колеса или другая микрошаговая настройка — поправьте именно здесь.

## Полярность моторов

В [config.h](../code/Giro_robot/Giro_robot/config.h):

- `BALANCE_SIGN` — если в режиме баланса моторы «убегают» не в ту сторону,
  поменяйте знак.
- `MOTOR2_INVERT` — если моторы при попытке ехать вперёд крутятся в разные
  стороны.
- `MOTOR1_SCALE`, `MOTOR2_SCALE` — если моторы несимметричны.
- `MOTOR_DRIFT_CORRECTION` — микрокомпенсация поворота при прямом движении.
