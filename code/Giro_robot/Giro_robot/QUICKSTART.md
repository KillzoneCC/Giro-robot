# Giro-Robot — Quick Start

## 1. Подключение

- **Arduino Nano** + USB
- **MPU6050**: SDA→A4, SCL→A5, VCC→3.3V, GND→GND
- **Мотор 1**: STEP→D3, DIR→D5
- **Мотор 2**: STEP→D9, DIR→D10

## 2. Сборка

1. Arduino IDE → открыть `Giro_robot.ino`
2. Установить: **Adafruit MPU6050**, **Adafruit Unified Sensor**
3. Плата: **Arduino Nano**
4. Загрузить

## 3. Первый запуск (пустой EEPROM)

1. Открыть Serial Monitor **115200**
2. Отправить **`c`** — запуск полной калибровки
3. Следовать подсказкам: 6 позиций (по ~5 сек на каждую)
   - **Позиция 1**: робот стоит **вертикально** (колёса вниз)
   - Позиции 2–6: переворачивать по инструкциям
4. После калибровки: базовый PID уже установлен
5. Поставить робота на пол, отправить **`v,0,0`** — попробовать баланс
6. Ручная подстройка PID: `p,300` `i,0.006` `d,0.004` и т.д.
7. Сохранить: **`w`**

## 4. Повторный запуск (EEPROM заполнен)

Робот загружает калибровку и PID — сразу готов к работе.

## 5. Скорость

**linear** в `v,linear,turn` — нормализованная величина **-1..1**, не м/с. 1 = макс. скорость.

## 6. Команды

| Команда | Действие |
|---------|----------|
| `v,0.5,0` | Вперёд 0.5, без поворота |
| `v,0,1` | Разворот на месте вправо |
| `s` | Стоп |
| `c` | Калибровка IMU (6 поз) |
| `z` | Запомнить нуль (держать 2 сек) |
| `z,0.5` | Установить нуль вручную (град) |
| `D` | Вкл/выкл отладку |
| `G` | Вкл/выкл график PID (Serial Plotter) |
| `p,280` | Kp=280 |
| `i,0.005` | Ki=0.005 |
| `d,0.004` | Kd=0.004 |
| `l,7500` | limit=7500 |
| `f,kp,ki,kd,lim` | Установить все PID |
| `P` | Показать PID |
| `w` | Сохранить PID в EEPROM |
| `e` | Очистить EEPROM |

## 7. График PID (Arduino Serial Plotter)

1. Открыть **Tools → Serial Plotter** (115200 бод)
2. Отправить **`G`** — включить вывод графика
3. Каналы: target, angle, error, P, I, D, output
4. Повторно **`G`** — выключить

## 8. Проблемы

- **MPU6050 not found** — проверить I2C и питание
- **Не балансирует** — подстроить PID (`p`, `i`, `d`), `w` для сохранения
- **Крутится на месте** — в `config.h` `MOTOR2_INVERT 1`
- **Калибровка заново** — `e`, перезагрузка, затем `c`
