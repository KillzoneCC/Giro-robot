# Giro-Robot — материалы для студентов

## Теория

### Один PID
Целевой угол = offset + linear×LEAN_SCALE. Один регулятор: угол → скорость моторов.
Робот наклоняется в сторону движения — колёса компенсируют падение.

### Ориентация
Только **pitch** (наклон вперёд/назад). Комплементарный фильтр: акселерометр (гравитация) + гироскоп.
Roll и yaw не используются — робот балансирует по одной оси.

### Twist-управление
- **linear** [-1..1]: вперёд/назад, 0 = стоять
- **turn** [-1..1]: влево/вправо, 0 = прямо
- turn=±1 при linear=0 — разворот на месте

### Единицы скорости
**linear** — нормализованная величина, **не** м/с.  
1 = максимальная скорость вперёд (≈14000 steps/s на мотор).  
Перевод в м/с: `v_m_s = steps_per_sec * (π * D / 200)`, где D — диаметр колеса в м, 200 — шагов на оборот (1.8°).

## Калибровка

1. **IMU (6 позиций)** — гироскоп и акселерометр
2. **Нуль** — угол «стоя» при вертикальном положении
3. **PID** — подстройка под механику

## Типичные проблемы

| Проблема | Решение |
|----------|---------|
| Колебания | Уменьшить Kp, увеличить Kd |
| Медленная реакция | Увеличить Kp |
| Дрейф | Добавить Ki |
| Крутится на месте | config.h: MOTOR2_INVERT 1 |
| Ускоряет падение | config.h: BALANCE_SIGN -1 |

## Структура кода

- `config.h` — параметры
- `orientation.h` — угол pitch (комплементарный фильтр)
- `imu_sensor.h` — MPU6050, калибровка
- `stabilizer.h` — PID (угол → моторы)
- `motors.h` — шаговики
- `twist_control.h` — linear, turn
