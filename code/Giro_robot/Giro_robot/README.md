# Giro-Robot — рефакторинг

Чистая архитектура для балансирующего гиро-робота на Arduino.

## Структура проекта

```
Giro_robot/
├── Giro_robot.ino    # Главный файл: конфиг, init, loop, Serial
├── config.h          # Параметры робота и настройки
├── motors.h          # Модуль двигателей (шаговики, twist)
├── imu_sensor.h     # Модуль датчика MPU6050
├── pid.h            # PID-регулятор
├── stabilizer.h     # Алгоритм стабилизации (каскад PID)
├── twist_control.h  # Фундамент управления (linear, turn)
├── calibration.h    # Калибровка IMU + EEPROM
└── fall_handler.h   # Падение и черновик автоподъёма
```

## Зависимости

- **Adafruit MPU6050** (`Adafruit_MPU6050`)
- **Adafruit Unified Sensor** (`Adafruit_Sensor`)
- **Wire** (встроено)

Установка через Arduino Library Manager: Adafruit MPU6050, Adafruit Unified Sensor.

## Команды Serial (115200 бод)

| Команда | Описание |
|---------|----------|
| `v,linear,turn` | Twist: linear [-1..1] вперёд/назад, turn [-1..1] влево/вправо |
| `s` | Стоп |
| `c` | Полная калибровка IMU (6 позиций) |
| `z` | Запомнить нуль (держать вертикально 2 сек) |
| `p,val` `i,val` `d,val` `l,val` | Fine-tune: установить Kp, Ki, Kd, limit в реальном времени |
| `f,kp,ki,kd,limit` | Установить все коэффициенты PID сразу |
| `P` | Вывести текущие коэффициенты PID |
| `w` | Сохранить PID в EEPROM |
| `e` | Очистить EEPROM (IMU + PID) |

Пример: `v,0.5,0` — вперёд. `p,300` — Kp=300. `f,280,0.005,0.0045,7500` — все PID. `w` — сохранить в EEPROM.

## Калибровка

**При пустом EEPROM:** робот ждёт команды `c`. Отправьте `c` — запускается полная калибровка:
1. IMU (6 позиций) — гироскоп и акселерометр
2. Базовый PID из config
3. Тюнинг PID: `p,val` `i,val` `d,val` `l,val` — подстройка, `w` — сохранить в EEPROM

**При наличии данных в EEPROM:** отдельные калибровки только вручную:
- `c` — калибровка IMU
- `z` — запомнить нуль

## Характеристики робота

- Диаметр колеса: 72 мм
- Масса: 1.1 кг
- Ширина: 134 мм, высота: 146 мм

## Плата

Arduino Nano. Пины: D3,D5 — мотор 1; D9,D10 — мотор 2. I2C — A4(SDA), A5(SCL).
